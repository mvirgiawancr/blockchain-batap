Sistem Akreditasi Berbasis Blockchain dengan AI

Analisis, Perancangan, dan Implementasi Sistem

1. PENDAHULUAN

1.1 Latar Belakang

Proses akreditasi program studi merupakan mekanisme penting dalam penjaminan mutu pendidikan tinggi di Indonesia. Saat ini, proses akreditasi masih menghadapi beberapa tantangan:

  • Proses manual yang memakan waktu dalam pengumpulan dan verifikasi dokumen
  • Kurangnya transparansi dalam proses penilaian dan audit trail
  • Kesulitan dalam memastikan integritas dan keaslian dokumen yang disubmit
  • Proses scoring manual yang rawan human error dan memerlukan waktu lama
  • Tidak ada sistem terpusat untuk tracking status submission

Sistem ini dikembangkan untuk menjawab tantangan tersebut dengan memanfaatkan teknologi blockchain (Hyperledger Fabric) untuk menjamin transparansi dan immutability, AI (Google Gemini) untuk otomasi ekstraksi data dan scoring, serta IPFS untuk penyimpanan terdesentralisasi.

1.2 Rumusan Masalah

1. Bagaimana merancang sistem akreditasi yang dapat menjamin transparansi dan audit trail yang jelas?
2. Bagaimana mengotomasi proses ekstraksi data dari dokumen LED dan LKPS untuk perhitungan scoring?
3. Bagaimana memastikan integritas dan keaslian dokumen akreditasi yang disubmit?
4. Bagaimana merancang arsitektur sistem yang scalable dan maintainable?

1.3 Tujuan Penelitian

  • Merancang dan mengimplementasikan sistem akreditasi berbasis blockchain dengan Hyperledger Fabric
  • Mengintegrasikan AI (Google Gemini) untuk ekstraksi otomatis data LKPS/LED dan scoring berdasarkan kriteria LAM-TEK 2025
  • Implementasi penyimpanan terdesentralisasi menggunakan IPFS/Pinata
  • Menyediakan antarmuka web yang user-friendly untuk UPPS dan Sekretariat
  • Membangun sistem scoring otomatis berdasarkan 7 kriteria LAM-TEK dengan 55 butir penilaian

2. LANDASAN TEORI

2.1 Blockchain dan Hyperledger Fabric

Blockchain adalah teknologi distributed ledger yang menyimpan data dalam bentuk block yang saling terhubung secara kriptografis. Karakteristik utama:

  • Immutability: Data yang sudah tercatat tidak dapat diubah
  • Transparency: Semua transaksi dapat diaudit
  • Decentralization: Tidak ada single point of failure

Hyperledger Fabric adalah framework blockchain permissioned yang cocok untuk enterprise. Fitur:

  • Channel untuk privacy antar organisasi
  • Chaincode (smart contract) dalam berbagai bahasa
  • Pluggable consensus mechanism
  • CouchDB untuk rich queries

2.2 AI dan Natural Language Processing

Google Gemini adalah large language model yang mampu:

  • Memahami dan mengekstrak informasi dari dokumen PDF dan Excel
  • Melakukan reasoning untuk perhitungan scoring
  • Memberikan rekomendasi berdasarkan analisis data

Dalam sistem ini, Gemini digunakan untuk:

  • Ekstraksi data numerik dari tabel LKPS (BOP, DPD, publikasi, dll)
  • Parsing struktur dokumen LED untuk validasi kelengkapan
  • Perhitungan skor per butir berdasarkan rubrik LAM-TEK

2.3 IPFS (InterPlanetary File System)

IPFS adalah protokol peer-to-peer untuk penyimpanan dan sharing file secara terdesentralisasi. Keunggulan:

  • Content-addressed: File diidentifikasi oleh hash (CID)
  • Immutable: File dengan CID yang sama pasti identik
  • Distributed: File dapat direplikasi di multiple nodes
  • Efficient: Deduplication otomatis

Sistem ini menggunakan Pinata sebagai pinning service untuk memastikan file tetap tersedia.

4.1 Analisis Kebutuhan Fungsional

Kebutuhan UPPS (Unit Pengelola Program Studi)

  • Upload dokumen LED dan LKPS
  • Lihat status submission dan progress

5.4 Implementasi AI Scoring Logic

Proses ekstraksi dan scoring menggunakan Gemini AI:

  1. Ekstraksi Teks: PDF di-parse dengan pdf-parse, XLSX dengan ExcelJS
  2. Prompt Engineering: Untuk setiap kriteria, dibuat prompt spesifik dengan contoh format data
  3. Parsing Response: Gemini mengembalikan JSON dengan field-field LKPS (BOP, DPD, publikasi, dll)
  4. Scoring Calculation: Berdasarkan rubrik LAM-TEK, hitung skor 0-4 per butir
  5. Aggregation: Hitung rata-rata per kriteria dan overall score

Contoh butir scoring:

Butir 2.3: Total Dana PS (BOP)
- Ekstrak nilai BOP dari sheet LKPS 4a
- Formula scoring:
  if (bop >= 50000000) score = 4
  else if (bop >= 30000000) score = 3.5
  else if (bop >= 20000000) score = 3
  else if (bop >= 10000000) score = 2
  else score = 0
  
Butir 4.6: Publikasi Ilmiah DTPS
- Ekstrak jumlah publikasi dari sheet 3b4
- Hitung persentase publikasi/NDTPS
- Score berdasarkan threshold LAM-TEK
