SISTEM AKREDITASI TERDESENTRALISASI

Blockchain-based Accreditation Management System with AI
LAM-TEK 2025 - 7 Kriteria Akreditasi

1. PENDAHULUAN

1.1 Latar Belakang

Sistem Akreditasi Terdesentralisasi merupakan sebuah platform berbasis blockchain yang dikembangkan untuk mendukung proses akreditasi program studi di lingkungan LAM-TEK (Lembaga Akreditasi Mandiri Teknik). Sistem ini mengintegrasikan teknologi Hyperledger Fabric untuk menjamin transparansi dan immutability data, IPFS untuk penyimpanan dokumen terdesentralisasi, dan Google Gemini AI untuk analisis dokumen otomatis berdasarkan 7 Kriteria LAM-TEK 2025.

1.2 Tujuan Sistem

  1. Menyediakan platform terdesentralisasi untuk pengelolaan dokumen akreditasi (LED dan LKPS)
  2. Memanfaatkan teknologi blockchain untuk menjamin integritas dan ketertelusuran data akreditasi
  3. Mengotomasi proses analisis kelengkapan dokumen menggunakan Artificial Intelligence
  4. Memfasilitasi verifikasi dan approval dokumen oleh Sekretariat LAM-TEK
  5. Memberikan notifikasi real-time kepada stakeholder melalui WebSocket
  6. Menerapkan sistem penilaian berdasarkan 7 Kriteria LAM-TEK 2025

1.3 Ruang Lingkup

Sistem ini mencakup implementasi Proof of Concept (PoC) Fase 1 yang meliputi:

  • Upload dan validasi dokumen LED (Laporan Evaluasi Diri) dan LKPS (Laporan Kinerja Program Studi)
  • Penyimpanan metadata dokumen di blockchain Hyperledger Fabric
  • Penyimpanan file dokumen di IPFS melalui layanan Pinata
  • Analisis otomatis menggunakan Google Gemini AI
  • Sistem approval/rejection oleh Sekretariat
  • Perhitungan skor berdasarkan 7 Kriteria LAM-TEK 2025
  • Notifikasi real-time menggunakan WebSocket

Sekretariat sekretariat.akreditasi.local Verifikasi dan approval dokumen 1 peer + CouchDB

3.1 Deskripsi Use Case

UC-01: Upload Dokumen

Aktor UPPS
Deskripsi UPPS mengupload dokumen LED dan LKPS untuk program studi yang akan diakreditasi
Precondition UPPS memiliki dokumen LED (PDF) dan LKPS (Excel) yang siap diupload
Main Flow 1. UPPS mengisi form program studi dan institusi
2. UPPS memilih file LED dan LKPS
3. Sistem memvalidasi format dan ukuran file
4. Sistem mengupload file ke IPFS/Pinata
5. Sistem menyimpan metadata ke blockchain
6. AI menganalisis dokumen secara otomatis
7. Sistem mengirim notifikasi ke UPPS
Postcondition Submission tersimpan dengan status "under_review"

UC-02: Verifikasi Dokumen

Aktor Sekretariat LAM-TEK
Deskripsi Sekretariat melakukan verifikasi dan memberikan keputusan terhadap submission
Precondition Submission dalam status "under_review"
Main Flow 1. Sekretariat melihat daftar submission
2. Sekretariat melihat detail submission dan hasil AI
3. Sekretariat mengunduh dokumen dari IPFS
4. Sekretariat melakukan verifikasi manual
5. Sekretariat memberikan keputusan (approve/reject)
6. Sistem update status di blockchain
7. Sistem mengirim notifikasi ke UPPS
Postcondition Status submission berubah menjadi "approved" atau "rejected"

8. KESIMPULAN

9.1 Hasil Implementasi

Sistem Akreditasi Terdesentralisasi telah berhasil diimplementasikan dengan fitur-fitur utama:

  • Upload dan penyimpanan dokumen LED/LKPS menggunakan IPFS/Pinata
  • Pencatatan metadata immutable di blockchain Hyperledger Fabric
  • Analisis otomatis dokumen menggunakan Google Gemini AI
  • Sistem verifikasi dan approval oleh Sekretariat LAM-TEK
  • Perhitungan skor berdasarkan 7 Kriteria LAM-TEK 2025
  • Notifikasi real-time melalui WebSocket
  • Keamanan dengan Helmet, CORS, rate limiting, dan validasi input

9.2 Keunggulan Sistem

  • Transparansi: Semua transaksi tercatat di blockchain yang dapat diaudit
  • Integritas Data: SHA-256 hash memastikan dokumen tidak diubah
  • Efisiensi: AI mengurangi waktu analisis manual dokumen
  • Desentralisasi: Tidak ada single point of failure
  • Real-time: WebSocket memberikan update instant kepada user

9.3 Pengembangan Selanjutnya

Untuk fase berikutnya, disarankan implementasi:

  • Sistem autentikasi dan otorisasi berbasis role
  • Dashboard analytics untuk monitoring performa program studi
  • Export report dalam format PDF/Excel
  • Integrasi dengan sistem informasi akademik (SISTER, PDDikti)
  • Multi-language support (Indonesia, English)
  • Mobile application (React Native)
  • Enhanced AI dengan fine-tuning model khusus LAM-TEK
