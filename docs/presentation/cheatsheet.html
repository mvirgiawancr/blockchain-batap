❓ KEMUNGKINAN PERTANYAAN & JAWABAN

Kenapa Hyperledger bukan Ethereum?
Permissioned = cocok data sensitif. Tanpa crypto = sesuai enterprise. Performance lebih tinggi. Ethereum = public, tidak cocok data rahasia.
Bagaimana jika AI salah scoring?
AI = second opinion/DSS, bukan penentu akhir. Asesor tetap review & tentukan skor final. Hasil AI & asesor dibandingkan untuk evaluasi.
Apa yang disimpan di blockchain?
Hash dokumen (verifikasi), metadata, status, skor, audit trail. Dokumen asli di IPFS.
Bagaimana keamanan sistem?
JWT auth, RBAC (role-based), Blockchain immutable, Audit trail, Permissioned network, IPFS content addressing.
Apa 7 kriteria LAM-TEK?
1. Visi Misi, 2. Tata Kelola, 3. Mahasiswa, 4. SDM, 5. Keuangan/Sarpras, 6. Pendidikan, 7. Penelitian & PkM.
Kenapa Google Gemini?
Multimodal (teks+gambar), Long context, API stabil, Cost effective. Arsitektur modular, bisa ganti model.
Rencana pengujian?
Unit Testing, Integration Testing, Functional Testing, Performance Testing (TPS), UAT. Semua di dev environment.
Apa novelty penelitian?
Integrasi Blockchain+AI untuk akreditasi (belum banyak). Spesifik LAM-TEK 2025. Hybrid on/off-chain. AI as second opinion.
